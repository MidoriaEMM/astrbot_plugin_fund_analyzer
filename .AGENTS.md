## Project purpose

An AstrBot plugin for real-time fund/stock queries and AI-driven financial analysis. Key capabilities:

- Real-time market data (funds & A-share stocks) via EastMoney HTTP API
- Quantitative analysis: 15+ technical indicators, backtesting, risk metrics
- Multi-agent debate analysis: 6 specialist agents → bull/bear synthesis → game-theory judge (9 LLM calls total)
- HTML report generation via Jinja2 + Playwright → PNG image

**Language:** Python 3.10+  
**Framework:** AstrBot v4.0+  
**Entry point:** `main.py` → `FundAnalyzerPlugin(Star)`

## Architecture notes

### LLM access

Never call an LLM directly. Always use the AstrBot provider:

```python
provider = self.context.get_using_provider()
response = await provider.text_chat(
    prompt=user_content,
    system_prompt=system_prompt,   # optional role definition
    session_id=unique_id,          # isolate from user chat history
    persist=False,
)
```

### Multi-agent debate flow (`stock/debate_engine.py`)

```
Phase 1 (parallel)  6 specialist agents via asyncio.gather()
Phase 2             Bull-case builder
Phase 3             Bear-case + rebuttal
Phase 4             Judge (Nash-equilibrium game theory)
```

To add a new agent: add its system prompt to `agent_prompts.py`, register it in `DebateEngine._run_phase1()`, and extend the result model in `DebateResult`.

### Data layer (`eastmoney_api.py`)

- Primary: EastMoney HTTP (custom async, *not* akshare)
- Fallback chain: Tencent Finance → Sina Finance
- Session rebuilds automatically on `ServerDisconnectedError`
- Random `User-Agent` rotation; DNS cache TTL 300 s

Cache TTLs (in-memory):

| Data type | TTL |
|---|---|
| Fund quotes | 30 min |
| Stock quotes | 10 min |
| Precious metals | 15 min |

### Image rendering (`image_generator.py`)

1. Render Jinja2 template → HTML string
2. Playwright headless Chromium → PNG (2× DPI)
3. Fallback: AstrBot's `HtmlRenderer`

### Quantitative analysis (`ai_analyzer/quant.py`)

`QuantAnalyzer` operates on a `pd.DataFrame` with columns `[date, close, high, low, open, volume]`. Public methods:

- `calculate_performance(df)` → `PerformanceMetrics`
- `calculate_all_indicators(df)` → `TechnicalIndicators`
- `run_all_backtests(df)` → `list[BacktestResult]`

All indicator maths is self-contained; no external TA library required.

## Conventions & constraints

- **Async everywhere.** All I/O must be `await`-ed; use `asyncio.gather()` for parallelism.
- **No blocking calls on the event loop.** Wrap CPU-heavy work in `asyncio.get_event_loop().run_in_executor(None, ...)`.
- **No direct `akshare` calls for price data.** Use `eastmoney_api.py`; akshare is a declared dependency for possible fallback but the primary path is the EastMoney HTTP API.
- **Yield results, don't return.** Command handlers must `yield` `event.plain_result()` or `event.image_result()` — AstrBot consumes them as async generators.
- **User preferences** are persisted to `user_settings.json` in the AstrBot plugin data directory (path from `self.context`), not hard-coded paths.
- **LLM calls must use isolated sessions** (`persist=False`) so analysis doesn't pollute the user's conversation history.
- **Jinja2 templates live in `templates/`.** Do not embed HTML in Python strings.
- **No investment-advice language** in any user-visible string. Keep the "data only, not investment advice" disclaimer.

## Adding a new feature — checklist

1. **New command** — add `@filter.command("...")` handler in `main.py`, wire data through `eastmoney_api.py` or `StockAnalyzer`.
2. **New technical indicator** — add calculation to `QuantAnalyzer` in `ai_analyzer/quant.py`, extend `TechnicalIndicators`, update prompt template in `ai_analyzer/prompts.py`.
3. **New debate agent** — add system prompt to `stock/agent_prompts.py`, extend Phase 1 in `debate_engine.py`, add field to `AgentReport`.
4. **New HTML report** — create template in `templates/`, render via `LocalImageGenerator.render_to_image()`.
5. **New data source** — add to `eastmoney_api.py`, keep fallback chain intact.

## Running & testing locally

```bash
# Install dependencies
pip install -r requirements.txt

# Install Playwright browser (first time)
playwright install chromium

# Run AstrBot with this plugin loaded
# (follow AstrBot documentation for plugin hot-reload)
```

There is no standalone test suite. To validate a change:

1. Load plugin in a local AstrBot instance.
2. Send the relevant chat command.
3. Verify the response (text or image) is well-formed.

For pure logic (quant indicators, debate engine), you can import the relevant class directly:

```python
from ai_analyzer.quant import QuantAnalyzer
import pandas as pd
qa = QuantAnalyzer()
df = pd.read_csv("sample_ohlcv.csv")
print(qa.calculate_performance(df))
```

## Out of scope for this plugin

- Real brokerage connectivity or order execution
- User authentication / account management
- Any persistence beyond in-memory cache + `user_settings.json`
- Non-Chinese (A-share / mainland fund) markets
